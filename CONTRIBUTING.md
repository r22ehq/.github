# Contributing to R22E Studio

Thank you for your interest in contributing to R22E Studio projects! We aim to build fast, minimal, and premium software.

## Guidelines
1. Keep PRs small and focused.
2. Adhere to the existing code style (Prettier/ESLint).
3. Ensure all tests and typechecks pass before requesting a review.
4. Provide a clear description of the problem and the proposed solution.

We review external contributions primarily for bug fixes and clearly scoped enhancements. If you're planning a major feature, please open an issue first to discuss the design.
